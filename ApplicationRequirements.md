# Design Specifications

## Mandatory Requirements:
  >1) A user should be able to create, read, update, display and delete a request.
  >2) For each delivery request a user is able to select a time and a delivery and pickup address.
  >3) A driver has the option to accept any request in the display menu
  >4) After a delivery has been done. A delivery confirmation screen will show up for both the user and the driver.
  
## Desirable requirements:
  >1) The user should be able to see real time location of the driver
  >2) The driver should be able to access a gps through the app to locate his delivery and pickup addresses (Google Maps integration)
  >3) The user and the driver should have the ability to rate each other after a delivery request has been done and the confirmation page popped up.
  >4) Authentication
  >5) Drivers should recieve notifications notifying them about any delivery requests within their radius.
  >6) After a Delivery request has been done Email Confirmation

--------------------------------------------------------------

User:
•	Ability to upload purchase order confirmation, picture of item that needs to be picked up 
•	Ability to set a time and a location when item is purchased and ready for delivery (maximum day delivery, max location)
•	Ability to review drivers
•	Ability to tip the driver
•	Ability for the user to check estimated time delivery and driver’s live location.(Google Maps Integration)
•	Ability to chat with Driver
•	Ability to pay the delivery fee using debit card information


Driver:
•	Ability to turn online or offline for delivery.
•	Ability to accept or decline a delivery request
•	Ability to use a GPS within the application. (Google Maps Integration)
•	Ability to review customer.
•	Ability to chat with User, or Phone call
